# RFD3

PDB structure in, partial-diffusion trajectory activations out. Requires pre-folded structures.

```
download → build_inputs → collect → train → eval → screen → steer
```

RFD3 uses **partial diffusion**: the input structure is noised to `partial_t` Å and denoised, conditioning activations on the structural context of the input.

| Hook | Module path | Collection |
|---|---|---|
| `token_initializer_outputs` | `token_initializer.process_s_init` | static (once) |
| `block6` | `diffusion_module.diffusion_transformer.blocks.6.transition_block` | every 5 steps |
| `block8` | `diffusion_module.diffusion_transformer.blocks.8.transition_block` | every 5 steps |
| `block12` | `diffusion_module.diffusion_transformer.blocks.12.transition_block` | every 5 steps |

Hooks config: `hooks=rfd3_partial`

## `partial_t`

| Value | Effect |
|---|---|
| 1–4 Å | Near-native; activations stay close to input |
| **5 Å** | Default — good signal/noise balance for classification |
| 8–10 Å | High noise; more design-like behavior |
