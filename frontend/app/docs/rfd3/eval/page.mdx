# Eval — RFD3

```bash
saffron eval \
  checkpoint_path=outputs/train/matryoshka_batch_top_k/block12/<timestamp>/final.pt \
  activations_path=outputs/collect/rfd3_train/activations/activations.h5 \
  metadata_dir=outputs/collect/rfd3_train/activations \
  hook_name=block12 \
  num_features=12 \
  top_residues=5
```

Top features ranked by AUROC (hazard vs benign) are written to `out_dir/top_features.parquet`.
