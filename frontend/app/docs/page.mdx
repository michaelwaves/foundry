# Saffron

Interpretability, hazard monitoring, and steering plugin for protein design models (RFDiffusion3, RF3).

Built on [foundry](https://github.com/RoseTTACommons/foundry) — the RoseTTACommons inference infrastructure — with minimal, non-invasive engine modifications to expose activation hooks.

**Prerequisite:** [uv](https://docs.astral.sh/uv/)

```bash
git clone https://github.com/RoseTTACommons/foundry && cd foundry
uv sync --extra sae
```

## Pipeline

```
collect → train → eval → screen → steer
```

<Cards>
  <Cards.Card title="collect" href="/docs/cli#collect" arrow>
    Run model inference with forward hooks. Writes activations to HDF5.
  </Cards.Card>
  <Cards.Card title="train" href="/docs/cli#train" arrow>
    Train a Matryoshka BatchTopK sparse autoencoder on collected activations.
  </Cards.Card>
  <Cards.Card title="eval" href="/docs/cli#eval" arrow>
    Score SAE features: activation frequency, top residues, AUROC per label.
  </Cards.Card>
  <Cards.Card title="screen" href="/docs/cli#screen" arrow>
    Run a trained detector bundle on new sequences or structures.
  </Cards.Card>
  <Cards.Card title="steer" href="/docs/cli#steer" arrow>
    Add or ablate directions in activation space during inference.
  </Cards.Card>
</Cards>

## Models

| Model | Input | Use case |
|---|---|---|
| **RF3** | sequence | Folding-time activation collection |
| **RFD3** | PDB structure | Partial-diffusion activation collection + steering |
