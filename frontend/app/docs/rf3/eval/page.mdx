# Eval — RF3

```bash
saffron eval \
  checkpoint_path=outputs/train/matryoshka_batch_top_k/block12/<timestamp>/final.pt \
  activations_path=outputs/collect/vfdb_rf3/activations/activations.h5 \
  metadata_dir=outputs/collect/vfdb_rf3/activations \
  hook_name=block12 \
  num_features=12 \
  top_residues=5
```

For hazard-vs-benign AUROC scoring, `metadata_dir` must contain a `labels.csv` with `name` and `label` columns.

Outputs a per-feature report to `out_dir/`.
