# Screen — RF3

Run a trained detector bundle on new sequences. Returns per-sequence hazard scores.

```bash
saffron screen model=rf3 \
  hooks=rf3_default \
  inputs=my_sequences.json \
  detector=outputs/detectors/rf3_block12/bundle.pt \
  out_dir=outputs/screen/my_sequences
```

Inputs JSON uses the same format as `saffron collect`.
