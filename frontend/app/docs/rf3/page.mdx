# RF3

Sequence-in, folding-trajectory activations out. No PDBs required.

```
fasta_to_sources → build_inputs → collect → train → eval → screen
```

| Hook | Module path | Collection |
|---|---|---|
| `to_si` | `diffusion_module.diffusion_conditioning.to_si` | every step |
| `block12` | `diffusion_module.diffusion_transformer.blocks.12.conditioned_transition_block` | every 50 steps |
| `block16` | `diffusion_module.diffusion_transformer.blocks.16.conditioned_transition_block` | every 50 steps |
| `to_r_update` | `diffusion_module.atom_attention_decoder.to_r_update` | every 50 steps |

Hooks config: `hooks=rf3_default`
